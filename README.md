# Flappy Bird

Небольшая игра в жанре Flappy Bird, разработанная на Python с использованием библиотеки Pygame.

## Реализовано

* управление птицей с помощью клавиши Space;
* физика движения с гравитацией и прыжком;
* случайная генерация труб;
* случайные ширина труб и расстояние между ними;
* проверка столкновений с трубами, верхней границей и землёй;
* подсчёт очков за пройденные трубы;
* постепенное увеличение скорости труб с ростом счёта;
* система достижений за определённые результаты;
* экран окончания игры и возможность начать заново;
* минималистичное чёрно-белое оформление.

## Запуск

Для работы требуется Python и библиотеки Pygame, Random.

Установка Pygame:


pip install pygame


Запуск игры:


python main.py


## Управление

Space — прыжок.

После проигрыша Space также используется для повторного запуска игры.
